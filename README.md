Nexion — Frontend

Interface web de um sistema de controle financeiro, construída em React com Vite.

🚧 Projeto em desenvolvimento. Os módulos de autenticação (login e cadastro) estão finalizados. As telas internas do sistema financeiro estão em construção.

Sobre o projeto

O Nexion é um sistema de controle financeiro dividido em duas camadas, cada uma em seu próprio repositório:

nexion-frontend (este) — interface do usuário
nexion-backend — API e regras de negócio
